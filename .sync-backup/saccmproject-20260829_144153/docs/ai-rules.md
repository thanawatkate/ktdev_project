# AI Rules Index

ไฟล์กฎหลักของโปรเจกต์นี้คือ `TEAM_RULES.md` (canonical rule file)

เอกสารนี้เป็นไฟล์ index สำหรับ AI tools ที่ต้องการจุดอ้างอิงแบบสั้น:

- อ่านและยึดกฎทั้งหมดจาก `TEAM_RULES.md`
- ถ้ามีความต่างระหว่างเอกสาร ให้ `TEAM_RULES.md` เป็นแหล่งความจริงหลัก
- กฎเชิงละเอียดสำหรับ Cursor เพิ่มเติมอยู่ใน `.cursor/rules/*.mdc`

เมื่อแก้กฎทีม ให้แก้ `TEAM_RULES.md` ก่อน และอัปเดตไฟล์อ้างอิงที่เกี่ยวข้องใน PR เดียวกัน
